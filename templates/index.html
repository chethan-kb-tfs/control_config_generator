Databricks SQL Insert Generator

Generate control_table_test and config_table_test INSERT statements locally. Nothing is executed against any database.

1. Control Table Generator

Each entry below is exactly one src_sys_cd + table_name combination, with its own target_bucket, primary_key, crt_by, and upt_by. It generates one initial row and one delta row. To add another table for the same src_sys_cd, or the same table under a different src_sys_cd, add another entry.

2. Config Table Generator

Each entry below is its own src_sys_cd. Inside an entry, each table produces one shared sql_config row, plus one raw_table_config row for every "Raw Config" you add to it. To add another table under the same src_sys_cd, or the same table under a different src_sys_cd, add another table or another entry.
